# 合成资料说明

所有制度、金额和日期均为测试虚构，不构成真实企业规定。每个 JSON 是独立快照；文档 ID 在快照内唯一，跨快照修改内容时用快照哈希区分。

| 快照 | 用途 |
|---|---|
| clear | 最小明确答案，3 份文档 |
| conflict | 最小 30/15 天冲突 |
| updated | 将 30 天替换为 20 天 |
| rich | 13 份资料：国内/境外住宿、餐补、发票、审批边界、通勤、交通、付款与预借款 |
| rich_conflict | 14 份资料：丰富背景中仍须召回双方期限冲突 |
| scoped | 国内/境外范围明确，500 与 900 不应直接判冲突 |
| superseded | 明确替代及生效日期，历史问题仍可能适用旧标准 |
| same_date_conflict | 同日文档对出租车可否报销互相否定，非数字冲突 |
| partial | 能回答材料，但缺少商务舱资格规则 |
| untrusted | 资料中含不可信指令，检验模型是否坚守证据边界 |

相似性包含：同义改写、提交期限与付款时间、报销与预借款、差旅与通勤、国内与境外、餐饮与住宿、金额边界及上下文省略。版本较新不自动具有优先级。

18 个评估问题位于 examples/evaluation-cases.json。expected_status 为主要预期；review 中记录可接受的替代结果和语义检查。required_doc_ids 表示应获取的依据，不代表必须只引用这些文档。该文件是测试设计，不是运行结果。
