# 验证材料评审入口

先查看 **验收用例/**，无需从时间戳猜测场景。23组正式用例覆盖六类题目必验点，另有10组稳定性重复记录。全部来自最终v4真实模型运行，不是模拟生成。

每组含：输入.json、实际输出.json、执行Trace.jsonl、运行元信息.json、评审结果.json、说明.md。Trace包含动作、参数、返回结果和简短依据。说明提供预期、实际结果和可复制命令。

- 正常：01_正常回答_国内住宿限额。
- 信息/资料不足：11_部分回答_商务舱资料缺失、13_信息不足_追问缺少指代、14_资料外问题_明年涨薪。
- 工具失败：19_工具失败_持续读取异常。
- 文档冲突与口语改写：04_文档冲突_期限冲突与口语改写；10_文档冲突_同日相反规定。
- 上下文：12_上下文追问_那境外呢。
- 上限：20_执行上限_明确未完成。
- 修改资料对照：21/22/23，固定问题仅更换资料。

[验证材料清单](验证材料清单.json)保存原始trace_id及四个原始文件的SHA256。内容未重写。机械通过不等于语义完全正确；语义审查的保留意见和历史失败均不删除。
