# 项目复盘

## 已观察到的难点

最难的是区分执行流程正确、引用原文存在和引用支持结论。真实模型曾把“未找到其他资料”挂到单一制度引用，虽然通过原文检查，仍不能据此证明资料库不存在其他规定。已收紧提示词并保留失败与复测；尚不能宣称完全解决。

第二个难点是检索覆盖。小型同义词归一化让 8 个开发用例 Recall@5 从 87.5% 到 100%，但开发集不能证明泛化。冲突判断还必须依赖读取原文和查证范围，不能靠数字差异或日期排序。

模型服务调试出现过认证失败、封禁和余额不足，最终 DeepSeek 官方接口成功。应将服务错误与业务资料不足分开，避免以 Mock 伪装模型成功。

## 下一步

已完成独立问法测试、完整提示词回归、异常处理和参数校验。后续产品改进应聚焦检索的独立集退步和概念边界歧义，而不是声称测试通过就具备生产可靠性。发布状态见交付清单。
