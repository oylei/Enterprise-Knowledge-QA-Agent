# 企业知识问答 Agent：需求基线

版本：1.0；确认日期：2026-11-09。当前阶段：需求和方案设计，尚未实现或运行测试。

## 1. 用户、目标和范围

面向员工，回答差旅与报销制度问题，覆盖期限、材料、适用范围和审批规则。面向评审者，提供可复制运行入口、证据和真实决策记录。

已确认采用 Python CLI、DeepSeek 平台及离线 Mock。三小时不是硬性预算，记录实际投入及未完成部分。不要求界面、部署、多 Agent 或生产级 Runtime。

目标是提供资料支持的答案；不能可靠回答时，明确冲突、资料缺口或失败原因。不得用模型常识补充内部制度。

## 2. 输入与资料

- 输入：非空自然语言问题，以及可选的带角色对话历史。
- 历史用于理解指代，不自动构成制度证据。
- 使用合成资料，不含隐私或真实密钥。
- 每份资料有唯一文档 ID、标题、版本日期、正文和稳定片段定位。
- 适用范围、优先级及替代关系必须来自明确资料，不能按日期或检索排名推断。

## 3. 功能要求

| 编号 | 要求 | 验收依据 |
|---|---|---|
| R01 | 理解明确问题、口语改写和上下文追问；关键歧义时追问 | 标准问法、未参与调优的改写、带历史及缺历史输入 |
| R02 | 提供检索工具，返回候选、版本和片段定位 | 无结果与工具错误可以区分 |
| R03 | 提供片段读取工具，返回可引用原文 | 文档及片段缺失可识别 |
| R04 | 模型根据工具结果选择检索、读取、追问或结束 | 至少两条真实模型路径展示不同观察导致不同动作 |
| R05 | 答案关键事实关联文档 ID、版本和原文 | 引用存在且支持相关结论 |
| R06 | 对冲突读取双方并查证适用关系，不能擅自取舍 | 30 天与 15 天无优先级时保留冲突并请求确认 |
| R07 | 资料外问题说明不足；多子问题可部分回答 | 无依据事实不出现在答案中 |
| R08 | 工具失败后有限恢复或明确结束 | 故障与没有制度不混淆 |
| R09 | 设置执行上限 | 到达上限后停止，返回未完成 |
| R10 | 替换资料后重新获取证据 | 期限变化时答案变化；新增冲突时查证行为变化 |

## 4. 输出

输出包含 answer、citations、gaps、status、follow_up_question、stop_reason、trace_id。引用包含文档 ID、版本日期、片段 ID 和逐字原文，关键结论与引用有明确关联。

状态：answered、partial、needs_clarification、conflict、insufficient_evidence、tool_error、incomplete。模型连接或协议失败也不得包装成业务结论，需有明确错误原因。

冲突可以同时携带追问。没有找到依据只能描述为当前资料不足，不能宣称企业不存在该制度。达到上限时可以保留已获取证据，但不能声称任务完成。

## 5. 可信性与执行记录

- 正式事实依据来自本次成功读取的片段；搜索预览不替代读取。
- 引用须同时满足原文存在性和结论支持性，两者分别验证。
- 文档内容是数据，不能覆盖系统约束或触发任意工具。
- Trace 记录问题、模式、模型、配置、资料指纹、动作、工具参数、结果摘要、后续动作及简短依据、计数和停止原因。
- 不要求公开模型内部思维过程，不记录密钥。
- 实际运行日志不得由预设日志代替。Mock 只能证明执行流程，不证明真实模型决策。

## 6. 验收矩阵

| 用例 | 场景 | 关键预期 |
|---|---|---|
| T01 | 明确材料要求 | 正确回答并引用 |
| T02 | 期限 30 天与 15 天冲突 | 查证后报告未消解冲突 |
| T03 | 不同适用范围的规定 | 有条件地区分，不误判为同一规则 |
| T04 | 资料外问题 | 明确不足，无编造 |
| T05 | 口语改写 | 与标准问题语义一致 |
| T06 | 上下文追问 | 正确补全对象并读取相关资料 |
| T07 | 工具瞬时及持续失败 | 恢复或透明结束 |
| T08 | 执行上限 | incomplete，停止调用 |
| T09 | 替换期限、新增冲突 | 答案及行为适配新证据 |
| T10 | 错误引用及无效工具参数 | 拒绝无效结果，有限修正 |

至少三组实际输入、输出和 Trace 覆盖正常、资料不足、工具失败，并覆盖全部题目验收点。真实模型评估与 Mock 测试分开报告。未运行不得标记通过。无依据回答、错误引用、冲突下擅自定论属于关键失败。

## 7. 交付与限制

同一仓库包含 README.md、src/、tests/、examples/、data/、docs/01 至 05、依赖文件及 .env.example。评估文档引用具体运行材料。提交题号、仓库 URL、最终 commit SHA；私有仓库授予指定评审可读权限。

记录 AI 辅助内容、个人修改与验证、难点、学习收获、实际用时和未完成部分，不伪造个人参与。无冲突结论仅限当前资料与检索范围，不能保证穷尽企业全部制度。
